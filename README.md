# Fieldnotes · Service Victoria 现场用户测试

为 MDC4502 Interface Design 搭建的主持式测试网页。基于六屏手机中保真 V3.1，测试主题为「Start with My Task」。这不是 Service Victoria 官方应用。

## 现场怎么用

1. 研究者在自己的设备上登录并打开网站，确认网络可用。网站保持私有，参与者使用这台设备操作。
2. 切换英文／中文测试说明；App 原型保留英文。向参与者介绍匿名操作记录，参与者自行勾选同意。
3. 填写三道背景题，阅读任务后点击开始。建议每次保持同一设备、窗口尺寸和输入方式。
4. 参与者依次完成查找租约信息、无结果恢复、寻找机构帮助三个任务。后两项起点由测试设置，分析时不要当作自然操作路径。
5. 研究者工具可暂停、记录原话及是否给过提示。避免边演示正确路径边收集独立完成数据。
6. 每项任务后填写 1–7 易用程度与可选回答；最后填写开放反馈。结束后确认保存状态，下载备份。
7. 研究者页查看路径、事件、反馈与时间，依据证据判定独立完成／提示后完成／未完成／受原型限制。之后准备下一位参与者。

## 六屏及三个任务

M01 首页 → M02 主题服务 → M03 搜索与建议 → M04 搜索结果 → M05 服务概览 → M06 帮助与联系。
任务 1 从首页开始，自然查找信息；任务 2 从预置无结果页开始；任务 3 从租约概览开始。
所有原型之外的入口均明确提示范围限制。搜索为有限样本目录，不是实时政府搜索。官方链接在新标签页打开；网页只记录离开原型的动作，不记录外站行为。

## 记录与解释

- 随机参与者编号；点击、搜索、页面路径、滚动深度、首个操作、主持人暂停与观察、回答和评分。
- 总时间：任务开始至结束的经过时间，包含暂停、切换标签和中断。
- 可见操作时间：只累计任务页可见且未暂停时的时间。不等同于注意力，也不能单独证明成功。
- 用户自报完成与研究者判定分开。刷新后可恢复未完成场次，进行中的任务恢复为暂停状态。
- 记录先存本机浏览器，再同步私有数据库。显示连接失败时保留本机副本并下载 JSON。清理浏览器数据会丢失尚未同步的记录。
- JSON 包含完整场次、问卷及笔记；CSV 为逐事件时间线。研究者页可按场次或全部导出。删除功能会同时删除本机与已保存记录。
- 网页不录音、不摄像、不录屏。笔记和回答不要填写姓名、联系方式或真实身份／租约细节。
- 当前版本的技术检查与模拟流程不是参与者研究，不应写成真实测试结果。

## 开发与验证

运行 `npm run dev`；构建使用 Sites 提供的构建流程。数据库迁移位于 drizzle/，生产部署时应用。身份验证按登录用户隔离记录。

检查：`node --test tests/*.mjs`；`npx tsc --noEmit`。本地浏览器走查覆盖恢复、任务路径、问卷、后台查看与保存。生产数据库不包含本地模拟测试记录。

## 测试网页 2.0 / 原型 V3.1 更新

- 页面采用用户提供的 Service Victoria SVG 标志，配合橙色斜切横幅、深蓝灰文字及浅灰背景。始终标明学生设计研究。原型的品牌色调整记为 V3.1；此前 V3 数据不应与新版数据无区别合并。
- 欢迎页「研究者：测试设置」选择同学认知走查或外部用户测试，填写轮次、原型版本和研究问题／Phase 1 证据引用。
- 可选择真实测试或试跑／技术检查。后台统计排除试跑及旧版未分类记录；两种参与者的测试数量只作进度提示。
- 同学场次建议预留课件中的 30 分钟；外部测试的 15–20 分钟为安排建议。两种模式提供不同主持提纲，保留同样三个任务供比较。
- 录像另行取得明确同意；拒绝录像仍可参与。网页不采集或上传音视频。启动和停止按钮只登记研究者已在外部设备上完成的动作，允许填写录像文件名／证据编号。屏幕录制是否可替代俯拍仍需教师确认。
- 研究者可按顺序逻辑、路径连续性、目标清晰度、文案理解、信息有效性和视觉层级记录观察，标记犹豫、误读、导航错误等。自动生成观察编号并关联页面、任务与事件序号。
- 后台支持将观察引用到设计决定，填写发现、修改前后、理由、版本、后续验证和计划／已修改／已复测状态。可导出 Markdown 报告，辅助整理最终 Design Documentation。
- 不要在独立尝试中展示主持判定参考或指示操作。协助必须标注，不能用「已记录提示」来消除干预影响。
- 新版通过类型检查及 5 项逻辑检查；浏览器操作验收因自动审批额度限制未能执行。未把任何试跑数据当作研究结果。
